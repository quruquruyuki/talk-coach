# 会話コーチ（talk-coach）

商談・相談・面談の最中に、会話を聞きながら
「確認漏れ」「あいまい・食い違い」「聞いてみる」「提案できる」「注意」を短いカードで出すWebアプリです。
会話が終わると、聞きそびれたこと・次にやること・お礼メッセージの下書きをまとめた振り返りを作ります。

- 音声は6〜15秒ごと（話の切れ目）に区切って文字にします（OpenAI）
- 25秒ごと（設定で変更可）に、Claudeが会話を読んで指摘を出します
- 長くなった会話は要約に畳んで送るので、1時間でも料金が膨らみにくくなっています
- 音声はどこにも保存しません。文字起こしと振り返りはこの端末（ブラウザ）の中にだけ保存します

## ファイル構成

```
index.html                                アプリ本体（GitHub Pagesに置く）
icon.svg                                  アイコン
supabase/functions/talk-coach/index.ts    AIを呼び出す関数（Supabaseに設置済み）
```

## 使うSecrets（ほかのアプリと共用・設定済み）
- OPENAI_API_KEY … 文字起こし
- ANTHROPIC_API_KEY … 指摘と振り返り
- ALLOWED_EMAIL … このアプリを使えるログイン用メールアドレス

## モデル（共通設定 app_settings の talk-coach）
- transcribe_model：gpt-transcribe
- advise_model：claude-haiku-5-5（会話中の指摘）
- review_model：claude-sonnet-5-5（振り返り）

## 使い方のメモ
- 会話中は画面を開いたままにしてください（iPhoneは画面を消すとマイクが止まります。戻ると自動で再開を試みます）
- 「今すぐ」：待たずに指摘を出す／「終盤」：次の約束・宿題を優先して見る
- カードの「済」で消せます。確認リストはタップで手動チェックもできます
- 録音することは、できるだけ相手にひと言伝えてから使ってください
